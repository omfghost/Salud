════════════════════════════════════════════════════════════════════
💾 HACER BACKUP DE TUS DATOS
════════════════════════════════════════════════════════════════════

Cada semana aproximadamente:

1. Abre HEALTH-app.html
2. Toca ⚙️ (esquina superior derecha)
3. Presiona "Exportar datos"
4. Se descarga un archivo JSON
5. Guárdalo en Dropbox, Google Drive, tu computadora, etc.

RESTAURAR:
1. Abre HEALTH-app.html en otro dispositivo o después de reinstalar
2. Toca ⚙️ Ajustes
3. Presiona "Importar datos"
4. Selecciona tu archivo JSON
5. ¡Tus datos aparecerán automáticamente!

📞 SOPORTE RÁPIDO
════════════════════════════════════════════════════════════════════

¿No funciona algo?

1. Cierra y abre de nuevo el navegador
2. Intenta en otro navegador (Chrome, Firefox, Safari, Edge)
3. En iPhone: Agrega a pantalla de inicio para mejor experiencia
4. Asegúrate de tener JavaScript habilitado
5. Limpia caché del navegador

¿Perdiste datos?

1. Si tienes backup JSON: Importa desde Ajustes
2. Si no: Desafortunadamente se perdieron
3. A partir de hoy: Exporta regularmente
